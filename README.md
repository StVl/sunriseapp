# Sunrise

Световой будильник для macOS: окно-лава-лампа, яркость которой и есть свет будильника. Спецификация — `SPEC.md` (дизайн-прототип «Плавно текущий свет в рамке»).

## Сборка и запуск

```bash
./scripts/build-app.sh      # → build/Sunrise.app (ad-hoc подпись)
open build/Sunrise.app
swift test                  # тесты логики (дни, расписание, кривые)
./scripts/make-dmg.sh       # → build/Sunrise-<версия>.dmg, universal (arm64 + x86_64)
```

Подпись выбирается сама:
- есть сертификат **Developer ID Application** в связке ключей → подпись с hardened runtime и разрешением на Apple Events (`Resources/Sunrise.entitlements`, нужно для Spotify);
- есть ещё и профиль notarytool `sunrise` → нотаризация и staple, `.dmg` открывается где угодно без предупреждений;
- иначе ad-hoc: получателю нужно `xattr -dr com.apple.quarantine /Applications/Sunrise.app`.

Профиль нотаризации создаётся один раз (пароль — app-specific с appleid.apple.com):
`xcrun notarytool store-credentials sunrise --apple-id <почта> --team-id ZV6B2JXP96`

Нужны macOS 14+ и Xcode (Swift 5.10+). Metal Toolchain не нужен: шейдер лампы компилируется при запуске.

## Структура

- `Sources/SunriseCore` — модель будильника, подписи дней, расписание, кривые яркости. Без UI, покрыто тестами.
- `Sources/Sunrise/Lamp` — лава-лампа: геометрия из `light.jsx` и Metal-шейдер (фон, капли, сглаженное слияние, свечение, блик, слой яркости).
- `Sources/Sunrise/UI` — панель настроек, барабан времени, плашка Armed, карточка Ringing, общие стили.
- `Sources/Sunrise/AppState.swift` — список будильников, редактор (черновик), ночной режим, звонок, snooze, затемнение, проверка срабатывания.

## Как устроено

- **Окно света** начинается за 2/10 длительности рассвета до будильника: 07:00 и 10 мин → свет с 06:58, полный в 07:08. Длительность 5–30 мин.
- **Список** (главный экран): будильники с переключателями, «+», Spotify, «Next: …» и **Go to sleep**. Клик по будильнику открывает редактор (Back без сохранения, Save включает будильник, Delete).
- **Будильники срабатывают всегда, когда включены**, на любом экране, а не только в ночном режиме. Пока хоть один включён, мак не уходит в сон (дисплей может погаснуть). Если экран при этом заблокируется, окно будильника не сможет показаться поверх блокировки, поэтому на ночь нужен Go to sleep.
- **Go to sleep** — плашка «Screen goes dark in 3…» (Cancel / Esc), затем «Night-night», затем ночной режим: плашка в углу, лампа на 7%, подсветка 1/16, дисплей не гаснет. × на плашке выключает показанный будильник.
- **Stop** — обратно к списку, лампа и подсветка остаются на 100%. Будильник остаётся включённым на следующие дни, разовый выключается сам.
- **Snooze** — обратно в ночной режим, тот же будильник через 9 минут.
- `Sources/Sunrise/AppDelegate.swift` — окно, меню, полноэкранный режим при срабатывании.
- `Resources/Icon` — иконка: `icon-classic-1024.png` (исходник, классическая сетка macOS) → `Sunrise.icns` для macOS 14–15; `Sunrise.icon` (full-bleed версия, собрана `scripts/icon-fullbleed.swift`) → `Assets.car` для macOS 26. Обе собираются в `build-app.sh`.

## Яркость на пике рассвета

Пункт меню **View → Max Brightness at Sunrise** (включён по умолчанию):

- **Подсветка** плавно поднимается вместе с рассветом с пользовательского уровня до 100% и возвращается обратно на Stop/Snooze и при выходе. Работает через приватный `DisplayServices`, поэтому приложение не пройдёт в Mac App Store.
- **EDR**: лампа рендерится в расширенном диапазоне и в пике светит ярче белого SDR. На XDR-экранах (MacBook Pro) это до ~1000 нит, на MacBook Air macOS даёт для полноэкранного слоя только ~1.25×.

## Ночь

**View → Dim Screen While Armed** (включён по умолчанию): пока будильник взведён и Sunrise на переднем плане, подсветка опускается до 1/16. Рассвет начинается почти из темноты. Если переключиться в другое приложение, подсветка возвращается к пользовательскому уровню. Во время рассвета уровень переустанавливается раз в секунду, чтобы автояркость не притушила экран. Уровень пользователя сохраняется в UserDefaults (`backlightToRestore`) и возвращается при следующем запуске, если приложение упало.

## Spotify

Через десктопное приложение Spotify и AppleScript, без Web API и Premium. При подключении macOS один раз спрашивает разрешение (Privacy & Security → Automation). Можно вставить ссылку на плейлист, альбом или трек (Share → Copy link); название подтягивается через публичный oEmbed. Пустая ссылка значит «продолжить последнее». На старте рассвета Spotify запускается в фоне, громкость растёт от 0 до 75 вместе со светом. Если звук мака выключен или ниже 50%, на время будильника он поднимается до 50%. На Stop/Snooze Spotify ставится на паузу, громкости возвращаются.

## Отладка

- **Debug → Ring Now** (⌘R) — сразу запустить рассвет; яркость нарастает за 10 с независимо от настроек.
- **Debug → Demo Timings** — рассвет за 10 с и snooze на 5 с вместо реальных минут.
- `open build/Sunrise.app --args --ring-now` — запустить сразу со срабатыванием (рассвет за 10 с).

## Ограничения беты

- Ad-hoc подпись меняется с каждой сборкой, поэтому macOS может заново спрашивать разрешение на управление Spotify после пересборки.
- Пока будильник взведён, приложение не даёт гаснуть экрану (power assertion). Вывода мака из сна по расписанию нет: крышка должна быть открыта.
- Если приложение упадёт, подсветка останется как была в момент падения; пользовательский уровень вернётся при следующем запуске.
